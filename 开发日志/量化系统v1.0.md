# 量化系统v1.0

## 策略管理

### 检索策略

- 策略名称

### 策略列表

- 策略名称
- 创建时间
- 策略因子罗列
- 操作

	- 删除

		- 将同步删除该策略形成策略结果

	- 编辑

		- 编辑策略的名称，策略名称是唯一的
		- 选择策略因子和相关限制

	- 运行

		- 策略结果将保存到数据库中，如果该策略已经在当天运行过（在数据库中已有策略结果），则系统提示该策略已在当天运行过。同时只能运行一个策略

	- 回测

		- 弹出运行窗口，显示回测log，回测log中包含交易明细，交易明细不要保存到数据库，支持一键复制log内容

### 创建策略

- 策略名称
- 策略ID
- 策略因子罗列
- 策略信号

	- 买入信号
	- 卖出信号

- 可配置的因子策略

	- 短期均线
	- PDI/NDI
	- 长期均线
	- 金叉
	- 死叉
	- PE范围
	- ROE限制
	- 净利润同比增长率限制
	- 负载率限制
	- 最低现金保障率（现金流/净利润比例）限制
	- 排序规则

		- 价格优先（单股低股价优先）
		- ROE优先（高盈利股优先）
		- PE优先（低估值股优先）
		- 成长性优先（高利润增长优先）

	- 股票范围

		- 沪深300
		- 全部
		- ...

	- 事件范围

		- 开始日期
		- 结束日期

	- 持仓策略

		- 最大持股数
		- 初始资金池

		- 股票名称

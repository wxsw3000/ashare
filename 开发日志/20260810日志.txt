    flowchart TD

▸ Thought Process
  Considering Complexities
  这是一个非常关键且极其专业的考量！在真实量化交易与模拟盘中，如果忽略了资金分配、交易摩擦（手续费/印花税）以及股数拆
  分规则，得出的收益曲线就会失去参考价值。

  对于这些复杂的资金管理与交易细节，我的思考和规划如下：
  ──────
  ### 1. 初始资金与资金分配规则 (Capital Allocation & Position Sizing)

  • 初始资金池 (initial_capital)：
      • 策略层可配置：支持在 UI 的策略配置中自定义（默认为 100,000 元，用户可自由设为 20万、50万等）。
  • 单标的上限与定额槽位 (Slot Allocation)：
      • 等额分仓（默认模式）：依据策略设置的最大持仓数 max_holdings（如 5 只），将初始资金等分为 5
      个资金槽，单槽预算为 20,000 元。
      • 滚存复利模式（可选模式）：平仓卖出后回笼的“本金+利润”留存给该槽位，下一次建仓时全额使用该槽位的最新资金。

  ──────
  ### 2. A股 / 可转债交易细节真实计算 (Trading Rules & Friction)

  • 一手拆分取整 (Round-lot Constraint)：
      • 股票：A股买入必须是 100 股的整数倍（一手）。


                           槽 位 可 用 资 金
    买 入 股 数  = lfloor ───────────────────────/100 rfloor × 100
                      买 入 单 价  × (1 + 佣 金 率 )

    *若计算所得股数不足 100 股（如高价股无法买满一手），则跳过建仓或提示资金不足。*

  • 可转债：买入必须是 10 张（手）的整数倍（每张面值 100 元）。
  • 零头资金保留：一手拆分后剩余的碎屑资金（如几百元），自动保留在该槽位或汇总为现金余量。
  • 交易费率与税费实扣 (Transaction Costs)：
      • 股票买入：扣除佣金（万分之三，最低 5 元）。
      • 股票卖出：扣除佣金（万分之三） + 印花税（千分之五）。
      • 可转债：免印花税，仅扣除佣金（万分之0.5～万分之1）。

  ──────
  ### 3. 买卖调仓的执行顺序与优先原则 (Execution Order & Selection Priority)

  1. 先卖后买 (Sell First)：
  在每日盘后更新时，优先执行当日 SELL 信号，先将触发卖出的股票平仓，把资金和槽位释放出来。
  2. 候选买入排队 (Buy Priority)：
  若当前空余槽位为 N 个，则从当日 BUY 推荐列表中，按策略指定的因子优先规则（例如 PE 最低、或双低值最低）精选排名前 N
  的标的进行买入建仓。
  3. 持仓已满保护：
  如果持仓已达 max_holdings 且当日无卖出信号，默认保持持仓不变，不强行换股，避免过度换手导致手续费损耗。
  ──────
  ### 4. 动态风控与离场机制 (Risk Control)

  • 固定止损线 (Hard Stop-Loss)：例如单标的相对于买入价亏损达 -8% 时自动触发出场。
  • 移动止盈线 (Trailing Stop-Profit)：例如从最高点回撤 -5% 时锁定利润离场。
  • 强赎风控 (针对可转债)：触及正股连续 15 日 > 130% 转股价时提示强赎离场。
  ──────
  ### 预设参数 vs 可自定义参数表

  为了保证系统既开箱即用又具备高度灵活性，我计划将这些条件设计为可调节的参数：

   参数项                               │ 默认值                               │ 作用与含义
  ──────────────────────────────────────┼──────────────────────────────────────┼─────────────────────────────────────
   初始资金 (initial_capital)           │ 100,000 CNY                          │ 模拟盘账户起步资金
   最大持仓数 (max_holdings)            │ 5 只                                 │ 同时持有的股票/转债最大数量
   单股上限模式 (allocation_mode)       │ 等额平铺                             │ 等额平铺 (固定 20%) 或 复利滚存
   交易佣金率 (commission_rate)         │ 0.0003 (万三)                        │ 真实交易佣金预扣
   止损阈值 (stop_loss_pct)             │ -8.0%                                │ 跌破即平仓风控线 (0 表示不开启)
   止盈回撤 (trailing_stop_pct)         │ -5.0%                                │ 最高点回撤平仓线 (0 表示不开启)
  ──────

▸ Thought Process
  Analyzing Transaction Costs
  是的！股票交易的手续费与税费早已完备地考虑在内，并且我们已经内置了专业的费用计算引擎模块 (cost.py)。

  在模拟持仓与实盘调仓结算中，系统会根据真实 A 股与可转债的交易规则，精准扣除每一笔交易摩擦：
  ──────
  ### 1. 股票交易费用实扣标准 (cost.py)

  • 买入阶段 (Deducted on Buy)：

    买 入 手 续 费  = max (成 交 金 额  × 0.00025, 5.0 元 最 低 门 槛 )

  • 买入总成本 = 成交金额 + 买入手续费。
  • 卖出阶段 (Deducted on Sell)：

    卖 出 佣 金  = max (成 交 金 额  × 0.00025, 5.0 元 最 低 门 槛 )

    卖 出 印 花 税  = 成 交 金 额  × 0.0005  (千 分 之 五 ， 仅 卖 出 收 取 )

  • 卖出净回收现金 = 成交金额 - 卖出佣金 - 卖出印花税。
  ──────
  ### 2. 区分“股票”与“可转债”费率模型

  为了真实还原不同品种的交易成本特征，持仓引擎会对股票与可转债应用不同的规则：

  • A股股票：执行上述 万2.5佣金(最低5元) + 千0.5印花税 标准。
  • 可转债：
      • 免征印花税（印花税为 0%）。
      • 佣金极低（支持配置为万分之 0.5 ~ 万分之 1，且无 5 元最低门槛限制）。
      • 这能真实反映可转债策略在日内/轮动交易中成本极低的制度优势。

  ──────
  ### 3. 在模拟持仓与收益率中的真实呈现

  • 实现盈亏 (Realized PnL)：

    单 笔 净 盈 亏  = 卖 出 净 收 回 现 金  - 买 入 总 成 本

  •
  持仓成本价：在持仓列表中，买入价格会自动加上买入佣金折算的成本，避免出现“虽然单价涨了却因为手续费亏损”的虚高现象。

  因此，您在面板上看到的总资产曲线和胜率，全部都是扣除所有券商佣金与国家印花税后的纯净净值！

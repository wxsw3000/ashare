  这两个脚本分别对应股票策略和可转债策略的命令行回测入口。下面是它们的作用和具体使用方法：
  ──────
  ### 1. 股票策略回测脚本：run_backtest.py

  • 适用场景：回测 A 股股票策略（包括动态多因子策略、PE优先、ROE优先、价格突破策略等）。
  • 底层调用的模块：runner.py。

  #### 💻 使用命令示例（在项目根目录下执行）

    # 1. 运行默认动态多因子策略 (默认区间 2024-01-01 ~ 2026-06-30)
    python -m MagicSTG.run_backtest

    # 2. 指定策略类型、回测时间段和股票池
    python -m MagicSTG.run_backtest --strategy dynamic_factor --start 2023-01-01 --end 2026-06-30 --universe csi300

    # 3. 运行 PE 优先策略，并将回测结果保存到 TiDB 数据库
    python -m MagicSTG.run_backtest --strategy pe --start 2022-01-01 --end 2026-06-30 --save-db

  #### ⚙️ 可选参数列表

  • --strategy：策略名称，可选 dynamic_factor（多因子）、pe（市盈率）、roe（净资产收益率）、price（价格突破）。
  • --start：回测开始日期，格式 YYYY-MM-DD（默认 2024-01-01）。
  • --end：回测结束日期，格式 YYYY-MM-DD（默认 2026-06-30）。
  • --universe：选股范围，可选 all（全市场）或 csi300（沪深300）。
  • --save-db：添加此标记会将回测计算得到的净值曲线与交易统计保存入数据库。
  ──────
  ### 2. 可转债双低策略专用回测脚本：run_cb_backtest.py

  • 适用场景：专门用于可转债双低轮动策略（即 转债价格 + 转股溢价率 × 100 排序低买轮动）。
  • 特点：从 TiDB 的 cb_daily_indicator 表读取历史衍生指标，按设定的轮动周期和资金模拟买卖及手续费扣除。

  #### 💻 使用命令示例（在项目根目录下执行）

    # 1. 运行默认参数的可转债回测 (2022~2026年，持仓10只，5天轮动)
    python -m MagicSTG.run_cb_backtest

    # 2. 自定义回测参数：测试更严格的价格上限（如120元）和3天调仓
    python -m MagicSTG.run_cb_backtest --start 2022-01-01 --end 2026-07-30 --capital 200000 --top 15 --max-price 120
  --rebalance 3

  #### ⚙️ 可选参数列表

  • --start：回测起始日期（默认 2022-01-01）。
  • --end：回测结束日期（默认 2026-07-30）。
  • --capital：初始回测资金（默认 100000.0 元）。
  • --top：每次轮动持仓的转债数量（默认 10 只）。
  • --max-price：价格过滤上限，高于此价格不买入（默认 130.0 元）。
  • --rebalance：调仓轮动周期天数（默认每 5 个交易日调仓一次）。
